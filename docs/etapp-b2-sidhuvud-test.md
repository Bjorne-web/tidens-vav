# Etapp B2 – Gemensamt sidhuvud

Enhetligt informationshuvud i Karta, Temaspår, Jämför och Om. Ändrar inte ordinarie sidnavigation, läsare, forskning eller innehåll.

## Test
1. Besök Karta, Temaspår, Jämför och Om: verifiera ett sidhuvud per vy.
2. Navigera flera gånger: kontrollera att inget dubbleras och att befintligt innehåll visas.
3. Kontrollera mobilens rubrikbrytning och avstånd.
4. Kontrollera att startsida, Tidslinje inklusive Gantt samt global sök är oförändrade.
5. Kontrollera att befintliga kort, länkar och filter fortfarande fungerar.
