## Gränsdragningar

- H030 avser **autentiska** Paulusbrev, inte hela den paulinska brevsamlingen eller omstridda attribueringar.
- H031, H033–H035 behandlar föreslagna tillkomstperioder som forskningsbedömningar, inte absoluta skrivår; olika akademiska dateringar förekommer.
- H032 handlar om det romerska templets förstörelse i Jerusalem år 70, som historisk händelse med stor religionshistorisk betydelse.
- H036 är ett flerårigt uppror, inte ett enskilt exakt daterat ögonblick.
