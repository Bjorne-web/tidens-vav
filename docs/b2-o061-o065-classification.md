# B2.3 – O061–O065: byggnadsverk och arkeologiska miljöer

Den genererade O-listan innehåller **O061–O065 men inte O066**. Luckan noteras och ett O066-innehåll ska inte hittas på. Därför omfattar denna omgång fem verifierade poster.

| ID | Post | Kategorisering och reservation |
|---|---|---|
| O061 | Göbekli Tepe | Neolitisk arkeologisk miljö; flera faser och omdiskuterad funktion |
| O062 | Baalbek | Flera byggnads- och bruksskeden; originalets mycket tidiga intervall är inte ett säkert daterat romerskt tempel |
| O063 | Puma Punku | Arkeologisk byggnadsmiljö i Tiwanaku-kontext |
| O064 | Nan Madol | Monumental bebyggelse i flera faser, inte ett enda byggnadsår |
| O065 | Longyougrottorna | Uthuggna bergrum; upphov och datering kräver separat källprövning |

Samtliga ges preliminärt området **Världshistoria** och tidstyp **arkeologisk period**, inte ett fastställt färdigställandeår. Detaljerade dateringsprövningar finns som separata C7-lager för dessa poster; denna PR ändrar inte dem. Originalposter, källstatus och årtal bevaras. Klassificeringsstatus är `pilot-proposal`, forskningsstatus `unknown`.

Regressionstester för äldre O-grupper använder framöver `O999` som stabil kontrollpost för oklassificerade ID. Det undviker omskrivningar varje gång nästa faktiska O-post klassificeras.
