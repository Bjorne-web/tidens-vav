# B2.3 – O013–O018

Preliminär innehållsklassificering av sex importerade O-poster. De är grova pedagogiska sammanställningar, inte vetenskapligt daterade enskilda händelser.

| ID | Innehåll | Metodisk gräns |
|---|---|---|
| O013 | Homo sapiens migration | Flera migrationer och vägar, inte en enda avresa |
| O014 | Grottkonst och symbolik | Grottmålningar i Europa representerar inte all tidig symbolkultur |
| O015 | Jordbruk och domesticering | Processer på skilda platser och med olika kronologier |
| O016 | Metallurgi, hjul, skrift | Separata innovationer, får inte tillskrivas ett gemensamt startår |
| O017 | Sumeriska städer och skrift | Urbanisering, kilskrift och bevattning har olika utvecklingsförlopp |
| O018 | Järnålder och krigföring | Regionalt varierande järnålderskronologier |

Alla klassificeras preliminärt inom Världshistoria. Originalårtal och originaltexter ändras inte. Forskningsstatus förblir `unknown`; ingen ny faktisk dateringsverifiering, inget gränssnittsingrepp.
