# B3.3 – Renare navigationsstatus

Återgång till Tidslinjen skapar inte längre ett tomt statusfält i dokumentet. Ett statusfält skapas bara när det finns ett meddelande att visa. Befintliga meddelanden döljs vid återgång.

Testet kontrollerar detta med simulerade DOM-händelser. Ingen ändring görs av Hem, Tidslinjens design, C7 eller forskningsdata. Detta är en teknisk förbättring, inte en ny designversion.

**Illustrativ etappstatus:** B2.3 klar → B3.1 klar → B3.2 klar → B3.3 pågår → B3.4 återstår.
