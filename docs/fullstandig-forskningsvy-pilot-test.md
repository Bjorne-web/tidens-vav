# Fullständig forskningsvy – separat testpilot
Testa via `/?fullreader=H045`, `/?fullreader=H005`, `/?fullreader=B001` och `/?fullreader=D001`.
Läsdata hämtas från samma godkända read-only-adapter. Ingen ändring av gammal panel eller normal navigering.
Kontrollera att forskningsposter presenteras med överblick, historiskt sammanhang, betydelse, begränsningar och källor endast när respektive fält finns. Ingen ny forskningsfakta skapas. Använd Tillbaka till Väven och Escape. Mobil: läsbarhet och återgång.
**Avgränsning:** endast query-aktiverad fulläsarpilot, ingen permanent navigation förrän design och postöppning godkänts.
