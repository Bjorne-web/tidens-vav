# B3.3 – Temaspår och fokusobjekt

Navigeringen från Tidslinjen till Temaspår skyddas mot ett saknat eller felaktigt fokusobjekt. Befintlig relationstilldelning och vald post bevaras.

Den godkända grafiska designen, källmaterialet och C7 ändras inte. Test i webbläsare behövs vid framtida synliga förändringar.
