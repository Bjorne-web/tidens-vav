# B2.3 – O049–O054, krig och väpnade konflikter

Skrivskyddad ämnesklassificering av sex historiska konflikter i originalkategorin `Krig`. Originalårtal och originaltexter ändras inte. Ursprunglig datering är markerad *ej faktagranskad*.

| ID | Post | Klassificeringsprincip |
|---|---|---|
| O049 | Puniska krigen | Tre konflikter under lång period, inte ett oavbrutet krig |
| O050 | Hundraårskriget | Flera etapper och vapenvilor, inte en enhetlig kontinuerlig strid |
| O051 | Trettioåriga kriget | Sammanflätade religiösa och politiska faktorer; undvik enkel religionskrigsreduktion |
| O052 | Amerikanska inbördeskriget | Avgränsad historisk konflikt; slaveriets centrala betydelse noteras för senare innehållsprövning |
| O053 | Första världskriget | Avgränsad global historisk konflikt |
| O054 | Andra världskriget | Avgränsad global historisk konflikt, med regionalt skiftande inledningsdatum |

Alla hör preliminärt till **Världshistoria**. Flerfasiga O049–O051 får tidsformen `historical-period`, medan O052–O054 får `historical-event`. Modellen ändrar inte hur originalspannet visas. `researchStatus` är fortsatt `unknown`; C7-källprövning hålls separat.
