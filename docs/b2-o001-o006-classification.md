# B2.3 O001–O006 – folk, migration och språkfamiljer

Denna pilot delar in sex poster från `originalEvents` under huvudområdet Världshistoria. Ursprungskategori `Folk`, postidentitet och årtal ändras inte. **Samtliga originalårtal är markerade som inte faktagranskade**.

| ID | Originalrubrik | Försiktig klassificering |
|---|---|---|
| O001 | Homo sapiens migration | Befolkningshistoria och migration |
| O002 | Amerikas urfolk | Urfolk och befolkningshistoria, inte en enda sammanhängande historisk period |
| O003 | Indoeuropéer | Språklig/etnolingvistisk tradition, inte en enda folkgrupp |
| O004 | Sino-tibetanska folk | Språkfamilj/befolkningshistoria, inte en enda historisk samhällsbildning |
| O005 | Semitiska folk | Språklig/etnolingvistisk mångfald, inte ett enhetligt folk eller religiös grupp |
| O006 | Bantu-expansionen | Långvarig migrations- och språkspridningsprocess |

Klassificering innebär varken dateringsgodkännande, antagande om enkel etnisk identitet, eller att originalarkivets mycket breda intervall är försvarbara. Samtliga behåller `researchStatus: unknown` och `classificationStatus: pilot-proposal`. UI och forskningslänkar ändras inte.
